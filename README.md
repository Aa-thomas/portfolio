# Aaron Thomas portfolio

The current site is a static portfolio built with HTML, CSS/Sass, and JavaScript.

The proposed handwritten-notebook rebuild uses SvelteKit and TypeScript, with private project/photo uploads and Markdown publishing. Read the [planning package](docs/portfolio-notebook/README.md), [specification](docs/portfolio-notebook/spec.md), and [desktop/mobile wireframes](docs/portfolio-notebook/wireframes.md).

Application implementation has not been authorized by this documentation publication.
